# GR TV Live v3

Εφαρμογή browser για αναπαραγωγή δημόσιων ελληνικών HLS/M3U8 streams και εμφάνιση EPG/XMLTV δεδομένων.

## Νέα χαρακτηριστικά v3

- Έλεγχος διαθεσιμότητας streams με timeout.
- Εξαγωγή και εισαγωγή αγαπημένων σε JSON.
- Δημιουργία M3U playlist από τα αγαπημένα.
- Εναλλαγή ελληνικών/αγγλικών στα εργαλεία v3.
- Επιλογή θέματος συστήματος.
- PWA manifest και βασικά metadata.
- Smoke tests για τα βασικά αρχεία.

## Εκτέλεση

Για απλή τοπική χρήση μπορεί να ανοίξει το `index.html`. Για σωστό έλεγχο CORS και M3U/HLS προτείνεται static server:

```bash
python3 -m http.server 8080
```

Άνοιξε μετά το `http://localhost:8080`.

## Έλεγχοι

```bash
node tests/smoke.mjs
```

## Σημαντικό

Η εφαρμογή δεν φιλοξενεί περιεχόμενο. Χρησιμοποιεί URLs δημόσιων πηγών που μπορεί να αλλάξουν, να απαιτούν token ή να μην επιτρέπουν embedding. Πριν από δημόσια δημοσίευση πρέπει να επιβεβαιωθούν οι όροι χρήσης των streams και των λογοτύπων.
